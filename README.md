# HOT Family EPG

XMLTV guide for the Israeli channel **HOT Family** (HOT Cinema Family), built from HOT's official TV guide at hot.net.il.

Guide URL: `https://raw.githubusercontent.com/YoavR1/hot-family-epg/main/hot_family.xml`
Channel id: `HOTFamily.il`

A GitHub Actions workflow refreshes it twice a day.
